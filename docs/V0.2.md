# PRAXIS OS v0.2 — Evidence Ledger + Decision Graph

## Purpose
v0.2 turns PRAXIS from a stateless reasoning kernel into a durable decision-intelligence substrate.

## Evidence Ledger
Claims are typed as fact, assumption, hypothesis, value, prediction or inference. Each claim carries confidence, provenance metadata and a lifecycle status: unverified, supported, disputed, refuted or stale. Status changes append immutable EvidenceEvents so the system can answer not only *what do we believe?* but *how did that belief change?*

## Decision Graph
Nodes represent decisions, facts, assumptions, hypotheses, variables, constraints, options, stakeholders, experiments, actions, outcomes and lessons. Directed typed edges encode support, contradiction, dependency, causality, influence, constraints, effects, tests, production and learning.

`impact_paths()` performs cycle-safe bounded traversal and compounds edge weights. It is intentionally not a causal estimator: weights are declared model parameters until a later causal/statistical engine validates them.

## Persistence
SQLite is the v0.2 reference persistence adapter. The domain services depend on a narrow store surface, allowing later PostgreSQL transactional persistence and Neo4j graph projection without changing the canonical models.

## API
- `POST /v1/evidence/claims`
- `GET /v1/decisions/{decision_id}/claims`
- `POST /v1/evidence/claims/{claim_id}/status`
- `GET /v1/evidence/claims/{claim_id}/history`
- `POST /v1/graph/nodes`
- `POST /v1/graph/edges`
- `GET /v1/decisions/{decision_id}/graph`
- `GET /v1/decisions/{decision_id}/impact/{node_id}`

## Architectural invariant
A graph edge is a modeled relationship, not automatically a verified causal truth. Provenance and epistemic status remain separate from topology. This prevents an attractive diagram from silently becoming “evidence.”

## v0.3 target
Quantitative Model Runtime + Scenario Lab: typed variables/units, formulas, deterministic recalculation, sensitivity analysis, scenario branching and prediction-vs-actual records.
