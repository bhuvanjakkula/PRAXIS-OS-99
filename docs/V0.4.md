# PRAXIS OS v0.4 — Integrated Simulation / Digital-Twin Foundation

v0.4 connects the Evidence Ledger, Decision Graph, Quantitative Runtime, and Scenario Lab around one traceable model.

## Central architecture

`Evidence -> Graph -> Bound Variables -> Deterministic Model -> Scenarios/Uncertainty -> Persisted Runs -> Observed Outcomes -> Calibration -> New Model`

### Invariants
1. Historical runs are immutable snapshots of the model/scenario used.
2. Calibration creates a successor model; it never rewrites history.
3. Graph propagation is a scenario generator, not proof of causation.
4. Monte Carlo is seedable and reproducible.
5. Formula execution remains deterministic and restricted.
6. Dimensional validation rejects incompatible arithmetic before persistence.
7. Variable bindings carry graph/evidence provenance for future traceability.

## Added components
- Persistent integrated models, scenarios, and runs in SQLite.
- Variable bindings to Decision Graph nodes and Evidence Ledger claim IDs.
- Dimensional unit algebra for currency/time/scalar semantics.
- Normal, uniform, and triangular uncertainty distributions.
- Seeded Monte Carlo with mean/stddev/min/P05/P50/P95/max summaries.
- Multi-variable sensitivity grids.
- Scenario comparison against baseline.
- Graph-to-model propagation using signed cumulative influence weights.
- Outcome calibration with explicit learning rate and successor-model lineage.

## Digital twin interpretation
A PRAXIS digital twin is not a claim that the software perfectly represents reality. It is a versioned, evidence-linked computational hypothesis about a system. Its value comes from explicit assumptions, reproducible simulation, comparison with observed outcomes, and reconstruction when wrong.
