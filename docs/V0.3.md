# PRAXIS OS v0.3 — Quantitative Model Runtime + Scenario Lab

v0.3 introduces a deterministic calculation plane beneath PRAXIS reasoning.

## Central invariant

**Language models interpret; the quantitative runtime calculates.** A model is explicit variables + units + formulas + scenario overrides. Formulas execute through a restricted AST evaluator, never arbitrary Python `eval`.

## Runtime

`QuantModel` contains typed `ModelVariable`s. Inputs have baselines; formula/output variables declare expressions. The runtime discovers dependencies, evaluates in topological order, rejects unknown references and cycles, and returns values with unit metadata.

## Scenario Lab

A `ScenarioSpec` is a branch over a baseline model. Overrides never mutate the baseline. This supports base/upside/downside/stress/counterfactual branches and later nested scenario trees.

## Sensitivity

One-variable sensitivity sweeps an input across explicit percentage changes and measures an output. v0.3 reports local range elasticity when calculable. Future versions add tornado analysis, distributions, Monte Carlo and global sensitivity.

## Deweyan prediction loop

`PredictionTracker` records predicted vs observed quantities and calculates absolute/percentage error. This is the bridge from simulation to experience: prediction → action → outcome → error → reconstruction.

## Cross-domain reference model

The tests model a product launch with customer/price inputs plus technology fixed cost, legal/compliance cost and human/training cost. Revenue, total cost and operating result are calculated deterministically, and scenarios can alter any explicit input.

## Next
